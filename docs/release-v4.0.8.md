# USB LinkMic 4.0.8

把 Android 手机当作 Mac 的麦克风，也能通过 USB 在手机和 Mac 之间共享网络。

这个版本更新了 Mac 和 Android 的应用图标，并修复 Mac Dock 图标的显示。

## 下载

|设备|安装包|
|---|---|
|Mac|[DMG](https://github.com/xxkingstuggle/usblinkmic/releases/download/v4.0.8/USBLinkMic-4.0.8-public.dmg) · [ZIP](https://github.com/xxkingstuggle/usblinkmic/releases/download/v4.0.8/USBLinkMic-4.0.8-public-macOS.zip)|
|Android|[APK](https://github.com/xxkingstuggle/usblinkmic/releases/download/v4.0.8/USBLinkMic-4.0.8-review.4.apk)|

Mac 下载 DMG 后，将应用拖进「应用程序」即可。配套 Android APK 已包含在 Mac 包内，连接手机后会检查版本，并在需要时引导安装。也可以单独下载 APK。

## 可以做什么

- 手机麦克风通过 USB 或 Wi-Fi 传到 Mac，支持试听、增益和静音；配合 BlackHole，可供会议、录音和直播软件使用。
- 手机通过 USB NCM 给 Mac 共享网络。
- Mac 通过 USB 给手机供网，无需手机 root。

## 系统要求

Mac 需要 macOS 26 及以上、Apple Silicon；Android 需要 8.0 及以上。手机给 Mac 自动共享网络需要 Android 11 及以上，并依赖 ROM 对 USB NCM 和系统共享的支持。
