# 安装和使用

先把手机接上，再决定这次要用麦克风，还是借一下网络。别急着把三个开关一起点亮，第一次从一个功能开始更容易看清哪里没准备好。

1. 下载和安装

到[最新 Release](https://github.com/xxkingstuggle/usblinkmic/releases/latest)下载 Mac 的 DMG，把 USB LinkMic 拖进「应用程序」。已经有旧版时先退出，再覆盖，应用数据不用删。

Mac 需要 macOS 26 及以上和 Apple Silicon。当前包使用本机 ad-hoc 签名，没有 Developer ID 公证。首次被系统拦截时，按[Apple 的打开 App 说明](https://support.apple.com/zh-cn/102445)核对来源后处理，不要为了安装去关闭系统保护。DMG 和 ZIP 是同一份应用，选一种就够了。

Android APK 也放在 Release 里。通常不用先单独下载，Mac 应用已经带了配套包，开始功能时会检查并在需要时原位安装或升级。厂商系统要求确认安装，就在手机上确认。签名冲突时会停下来，不会擅自卸载或清数据。

2. 让 Mac 找到手机

用能传数据的 USB 线连接，解锁手机，在 Android 开发者选项里打开 USB 调试。手机弹出电脑信任提示时，确认是自己的 Mac 再允许。回到应用点「刷新」，选中对应设备。USB 调试的系统设置可参考[Android 官方 ADB 说明](https://developer.android.com/tools/adb)。

列表为空时，先换线或 USB 口，再检查信任提示。能充电并不等于这根线能传数据。列表里有多台设备时，确认选对了再开始。

3. 先试手机麦克风

打开「手机麦克风」，在设置里选择 USB 和「本机试听」，确认输出是耳机或你想用的扬声器，再点「开始」。手机第一次会请求系统录音权限，允许后继续原操作。已授权的后续请求不再多加一层应用内确认。

对着手机说话，看有效帧和电平有没有变化，再听声音。用耳机试听更方便，手机离扬声器太近可能啸叫。录音权限被拒绝时先处理权限，不要反复点开始；系统不再弹窗时，需要到手机的应用权限设置里恢复。

想调音量，可以改增益或静音。用完点「停止」，需要结束所有任务就点右上角「全部停止」。

4. 给会议或录音软件当麦克风

先单独安装[BlackHole](https://github.com/ExistentialAudio/BlackHole)，常用的两声道版本就能作为音频传递设备。USB LinkMic 的用途改成「虚拟麦克风」，输出选对应的 BlackHole，保存后重新开始。

然后去会议、录音或直播软件里，把输入设备也选成同一个 BlackHole。只改 USB LinkMic 这一边，另一个软件还在读 Mac 自带麦克风，当然听不到手机。遇到采样格式不支持或设备找不到，先看应用给出的具体错误。

5. 手机给 Mac 供网

让手机自己先有可用网络，再在 Mac 选择「手机网络给 Mac」并开始。应用会处理 NCM 模式切换、USB 重新连接和共享准备，这时设备短暂消失是可能发生的，先看阶段提示。

这条自动路径需要 Android 11 及以上，还要看 ROM 的支持。准备期间别再去系统共享页来回切 USB 热点，避免系统把 USB 模式改成另一种协议。

显示「已连接」后，打开你实际要用的网站试一下。若 Mac 仍走 Wi-Fi，到系统网络设置检查 USB 网络服务及优先顺序。应用不会替你重排其他网络，也不会因为某个公网探测目标超时就主动拆连接。

共享切换可能打断原来的 USB 音频，网络准备好后再手动开始麦克风。停止会恢复本次改动；借用的原有共享保留。

6. Mac 给手机供网

先确认 Mac 自己能上网，再选「Mac 网络给手机」。首次使用要在手机上允许系统 VPN 请求。这里是把请求转回这台 Mac，不需要另买 VPN 服务。

等 VPN 和 USB 转发通道就绪，再在手机上打开要用的网站或应用。当前转发范围是 IPv4 TCP、UDP。另一个 VPN 正在运行时，系统可能无法同时保留两个 VPN，要先确认自己需要哪一个。

两个供网方向互斥，切换时先等上一项停止。DNS 和路由可以在设置里调整，不熟悉的话先保留默认值。

7. 不插线时用 Wi-Fi 音频

让两端处于同一可信局域网。Mac 设置选择 Wi-Fi，填这台 Mac 在该局域网里的 IPv4 地址，不能用127.0.0.1代替。把 Mac 显示的地址、音频端口和配对码填到手机，打开手机的 Wi-Fi 音频入口再开始。

Wi-Fi 音频没有传输加密，不要放在不信任的公共网络里使用。地址变化、防火墙或客户端隔离，都可能让两端连不上。

8. 停止、恢复和看日志

正常用完先停止，再拔线。显示「正在停止」时，程序还在确认手机停止或恢复 USB，别把等待当成已经完成。恢复失败会保留记录；手机已经拔掉时，可能需要接回同一台手机再重试。

需要反馈问题，写清哪一个功能、点过什么、手机型号和系统版本，再从「日志」页导出记录。日志有脱敏处理，发出前仍要自己看一遍。Mac 本地记录在`~/Library/Application Support/USBLinkMic-v4/diagnostics.log`，里面不保存录音 PCM。

维护者已反馈当前版本使用正常。其他机型的权限拒绝、反复插拔、长时间运行和复杂网络组合仍有待逐项验证，别把当前设备的顺利使用当成所有设备的承诺。
