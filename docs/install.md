# 使用指南

## 安装

从 [最新 Release](https://github.com/xxkingstuggle/usblinkmic/releases/latest) 下载 `.dmg`，打开后将 USB LinkMic 拖入「应用程序」。也可以下载 Mac ZIP，解压后拖入同一位置。更新时先退出旧版，再覆盖应用即可。

当前 Mac 包使用 ad-hoc 签名，尚未经过 Apple 公证。首次打开被 macOS 拦截时，请确认下载来源，并按照 [Apple 的说明](https://support.apple.com/zh-cn/102445)处理。

Android APK 已包含在 Mac 应用中，也可以从 Release 单独下载。连接手机并开始功能后，Mac 会检查配套版本，在需要时安装或升级。手机弹出安装确认时，按系统提示操作。遇到签名冲突，请先核对已有应用的来源。

## 连接手机

1. 用支持数据传输的 USB 线连接手机和 Mac。
2. 在 Android 开发者选项中打开 USB 调试。
3. 解锁手机，允许来自这台 Mac 的电脑信任请求。
4. 在 USB LinkMic 点「刷新」，选中手机。

USB 调试的设置可以参考 [Android 官方说明](https://developer.android.com/tools/adb)。

## 手机麦克风

打开「手机麦克风」，在设置中选择 USB 连接和「本机试听」，确认输出设备后点「开始」。首次使用时，在手机上允许系统录音权限。

对着手机说话，Mac 会显示收到的音频帧和实时电平。建议戴耳机试听，避免手机靠近扬声器产生啸叫。增益和静音可以在应用内调整。

用完点「停止」。右上角的「全部停止」可以结束当前所有任务。

## 给会议、录音和直播软件使用

1. 安装 [BlackHole](https://github.com/ExistentialAudio/BlackHole)，通常选择两声道版本。
2. 在 USB LinkMic 中将用途设为「虚拟麦克风」，输出设备选择 BlackHole，保存并开始。
3. 在会议、录音或直播软件中，将麦克风输入也设为同一个 BlackHole。

「本机试听」用于耳机或扬声器播放。其他软件需要通过 BlackHole 接收手机声音。

## 手机网络给 Mac

先确认手机自身可以联网，再选择「手机网络给 Mac」并开始。

应用会切换 USB NCM 模式、等待 USB 重新连接并准备网络共享。这个过程中设备可能短暂从列表消失。等待期间，避免同时在手机系统设置中切换 USB 热点。

自动共享需要 Android 11 及以上，并且 ROM 开放了相关能力。连接后，如果 Mac 仍优先使用 Wi-Fi，可以到系统网络设置检查 USB 网络服务及优先顺序。

USB 模式切换可能中断已有的音频连接。网络准备好后，可以重新开始麦克风。

## Mac 网络给手机

先确认 Mac 自身可以联网，再选择「Mac 网络给手机」并开始。首次使用时，在手机上允许系统 VPN 请求。

这项功能通过 USB 将手机的网络请求转交给 Mac，支持 IPv4 TCP 和 UDP。如果手机已有其他 VPN 正在运行，需要先选择要使用的 VPN。DNS 和路由可以在应用设置中调整。

两个供网方向互斥，切换前请先停止当前任务。

## Wi-Fi 音频

让手机和 Mac 连接同一可信局域网。在 Mac 设置中选择 Wi-Fi，填写 Mac 的局域网 IPv4 地址，再把显示的地址、端口和配对码填到 Android App 中，开启 Wi-Fi 音频。

`127.0.0.1` 是设备自身的地址，不能用来连接另一台设备。Wi-Fi 音频未加密，请勿在不可信的公共网络中使用。

## 常见问题

### Mac 找不到手机

检查线缆是否支持数据传输、USB 调试是否开启，以及手机是否已允许这台 Mac。解锁手机，重新插线后点「刷新」。

### 能看到电平，会议软件却没有声音

检查 USB LinkMic 的输出和会议软件的输入是否都选择了同一个 BlackHole。使用耳机试听时有声音，并不代表其他软件已经选对输入。

### 手机不再弹出录音授权

到 Android 的应用权限设置中，为 USB LinkMic 开启麦克风权限，再回到 Mac 重新开始。

### 已连接，但打不开网页

「已连接」表示设备链路和共享通道已就绪。请继续检查提供网络的一端是否能联网，以及 Mac 当前使用的网络出口、DNS 和手机上的其他 VPN。

### 停止后仍显示正在恢复

停止任务需要关闭手机端任务、释放转发并恢复 USB 设置。请等待状态完成；如果手机已拔掉，接回同一台手机后再重试。恢复失败的详情会显示在日志中。

### 如何反馈问题

在「日志」页导出记录，连同应用版本、手机型号、系统版本和复现步骤提交到 [Issues](https://github.com/xxkingstuggle/usblinkmic/issues)。上传前检查并删去个人信息。
